模型边界与名词

时间与库存：每日均匀到达，月增长在月初切换。数据年龄从采集开始计算；热缓冲 ≤ 标准层年龄阈值 ≤ 深冷层阈值。非留存部分热缓冲后删除，留存原始与成品分别设置最终删除期。

任务与卡时：GPU 系数为有效计算卡时，两地都按利用率折算；已含读写和等待的实测系数，应把对应利用率设为 100%。GPU 单价按含主机资源的单卡实例预算；CPU 核时仅填写额外独立 CPU 工作，避免重复计费。

简化数据路径：任务均读取新原始数据；同地输入按同一有序样本子集复用一次，任务产物汇集到打包位置，再形成成品。未模拟完整 DAG、历史重跑或缓存淘汰；输入共享假设不成立时应重新核算。成品延迟只移动输出时间，不模拟排队。

IDC：已有容量为明确预留给本工作负载的容量；已有资产净值填入剩余待摊金额。新容量按整块采购、采购月开始折旧，到期不再计折旧，仍保留容量和运营费；未自动更新硬件。额外采购余量 20% 表示需求 × 1.2，不是 80% 使用水位。

网络与读取：两地传输单价应包含该路径全部按流量收取的费用；与固定链路费不能重复报价。内网免流量不等于免请求或免取回。归档读取按每次独立恢复和临时副本预算；各项应以地域、对象大小及合同规则复核。

未覆盖：采集、标注人工、灾备及多云副本、平台专有处理费、复杂合同阶梯、独立 CPU 服务器采购、机房网络建设、资产融资、交付重试、历史批量迁移、资源上线时间。请求和控制服务仅列预算项。累计数值只覆盖所选时间窗口，不是含期后最低保存义务的完整 TCO；吞吐和 SLA 未验证时不作可行性承诺。

供应商资料快照

切换厂商只更新容量价格与最低保存期，不自动替换算力、恢复或链路报价。五家表中冷层名称并不等价；资料查询日期不等于报价生效日期。

业务体量使用十进制 TB/PB。报价表原单位 GB 的字节定义需单独核实；当前容量默认按 GiB 演示，网络预算按十进制 GB。自定义报价可分别调整。
